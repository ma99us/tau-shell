# TauShell Product Vision

TauShell is a desktop AI workspace orchestrator for terminal-native coding agents.

Core pillars:
- Session Persistence
- Session Restoration
- Agent Attention Detection
- Mobile Notifications
- Remote Interaction
- PowerShell-first Experience (WSL2 is an experimental, optional per-session runtime; see [`docs/wsl/`](../wsl/))
- Tool Plugin Ecosystem
- Secure Environment Injection
- Workspace Management
