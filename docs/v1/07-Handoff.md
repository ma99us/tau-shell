# Engineering Handoff

## Recommended Stack

Backend: Go
Frontend: React + Tailwind
Realtime: WebSocket
Persistence: YAML + SQLite
Notifications: ntfy

## Key Design Principles

- AI tools are unmodified.
- PowerShell remains first-class.
- Tool integrations are plugin driven.
- Configuration is human editable.
- Session recovery is a core capability.

## Future Features

- Slash-command abstraction
- Model selector UI
- Workspace templates
- Cross-machine sync
- Agent health monitoring
