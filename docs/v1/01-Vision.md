# TauShell Vision

TauShell is an AI workspace orchestrator for terminal-based coding agents.

## Goals
- Persist and restore AI sessions
- Attention detection
- Mobile notifications
- Remote terminal interaction
- Tool-specific automation
- Environment isolation per session
- UTF-8 and terminal compatibility management

## Primary Users
Power users running Claude Code, Copilot CLI, Gemini CLI, Aider, OpenCode, and future agentic TUIs.
