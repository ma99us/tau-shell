# MVP Roadmap

> **Historical roadmap:** Use [docs/v2/16-roadmap.md](../v2/16-roadmap.md)
> and [docs/v2/20-mvp-backlog.md](../v2/20-mvp-backlog.md) for current scope.
> Phase 1 targets a local Windows desktop GUI; the current CLI/TUI is
> transitional. Mobile dashboards, remote access, remote web interfaces, and
> notifications are not Phase 1 deliverables.

## Phase 1
- ConPTY hosting
- Session registry
- Notifications
- Mobile dashboard

## Phase 2
- Tool plugins
- Session resume
- Environment injection

## Phase 3
- Remote interaction
- Workspace restore
- Snapshot replay

## Phase 4
- Rich state detection
- Agent orchestration
- Multi-agent workspaces
