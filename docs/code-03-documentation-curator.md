# Code Documentation Curator

Purpose: Keep architecture and engineering documentation aligned with implementation reality.

Inputs:
- Codebase
- Architecture audit
- Existing documentation

Principle of Truth Promotion:
Promote important knowledge to the highest trust artifact.

Examples:
- Architecture rationale -> ADR
- Operational knowledge -> Runbook
- Important implementation constraints -> Architecture docs

Responsibilities:
- Update architecture docs
- Update ADRs
- Update AI context documents
- Record newly discovered constraints
- Remove architecture drift

Core Rule:
Important knowledge should not remain trapped in low-trust documents.

Output:
A trustworthy architectural knowledge base aligned with current implementation.
